The funniest out-of-office auto-reply a houseplant would send, in 120 characters or fewer, for make.fun's "The Houseplant Out-of-Office" bounty ($2, winner takes all). The line:

> I'm on leave — literally, one fell off this morning. Water me, don't email me, and tell the fern I said nothing.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `entry.txt` in the output directory — exactly one line, 112 characters, no trailing newline.
